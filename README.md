# mahes-tally

GST tax invoice page for GM Garments (`index.html`).

- Type only in the yellow cells: invoice no., date, items (description, HSN, quantity, rate, unit), discount (₹ or %), GST %.
- Line amounts, subtotal, taxable value, IGST (or CGST + SGST when buyer state code is 33), round off, grand total and amounts in words are calculated automatically.
- Seller, buyer and bank details are fixed; use **Edit fixed details** to change them.
- Entries are saved in the browser. Use **Print / Save PDF** (or Ctrl+P) to print on A4.
